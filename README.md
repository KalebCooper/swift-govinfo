# swift-govinfo

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Repository infrastructure for a Swift package for GovInfo published documents.

## Status

Infrastructure only. No API, products, models, tests, or document retrieval are implemented.
No release or remote repository is configured. Source build, portability, and documentation gates
are pending; a scaffold check does not establish those results.

## Usage

No callable API is available. See [implementation readiness](IMPLEMENTATION_READINESS.md).

## Requirements

Swift 6.2 or later, Swift 6 language mode. The manifest declares iOS 26, macOS 26, tvOS 26,
visionOS 26, and watchOS 26. Linux and Android support remains unverified.

## Installation

No consumable product is available to install. The manifest intentionally has no dependencies or
targets; networking dependencies and their version floors await integration validation.
